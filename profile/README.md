## Overview
Locus Map for Windows is built around a straightforward locus map app interface that keeps route planning, offline maps, and GPS tracking within easy reach while you're preparing for a hike. It's designed for people who spend time on trails without reliable signal, so downloaded maps, saved routes, and recorded tracks all stay available offline. From planning a weekend route to reviewing a finished hike, the interface keeps the whole trip in one place.
